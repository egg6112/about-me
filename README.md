## GitHub Pages の有効化方法

まだ有効化していない場合は、以下の手順で設定してください。

1. このリポジトリの **Settings** を開く
2. 左メニューの **Pages** をクリック
3. **Source** のドロップダウンで `main` ブランチを選択
4. **Save** を押す
5. しばらく待つと上記の公開URLでアクセスできるようになる
